# Briefs for the product chats

One brief per product. Each is self-contained: paste the whole file into that product's chat (or attach it). It says where the product stands on the site, what I need confirmed, how the demo should work, what to hand back, and the shared technical contract.

| Product | Brief |
| --- | --- |
| VeriChain | `verichain.md` |
| VeriCrypt | `vericrypt.md` |
| Sovereign ERP | `sovereign-erp.md` |
| OMC | `omc.md` |
| AgentSeed | `agentseed.md` |

## How to run a round

1. Paste a brief into the product chat. It answers the questions and builds the demo.
2. Ask it to hand back the files listed under "What to hand back".
3. Bring the result here (the files, or the product repo commit). I check it with `npm run verify`, fold the home-page changes into `family.json`, and make the next checkpoint.

Briefs reflect what I knew at the checkpoint they ship in. If a product chat tells you something that contradicts a brief, the chat is right; bring the correction here.
