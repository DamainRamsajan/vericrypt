Assumptions

  • All date arithmetic uses the as-of time 2026-10-22T02:34:33Z.
  • Quantum status is decided by algorithm family (Shor's algorithm breaks RSA, finite-field DH/DSA and elliptic-curve schemes). The only timing assumption is the Mosca check, which uses the horizon you supplied; the default is an assumption, not a prediction.
  • NIST IR 8547 is an initial public draft (Nov 2024); its dates may change before final publication.
  • CA/Browser Forum lifetime caps (398 -> 200 -> 100 -> 47 days) bind publicly trusted TLS certificates only. Scope is taken from the issuers you declare; undeclared issuers are reported as 'applies only if publicly trusted'.

Limitations

  • Only the files and endpoints you pointed the tool at were examined; see Coverage for everything skipped and why.
  • PKCS#12 and Java keystores are not opened. Encrypted private keys are inventoried but their algorithm is not visible.
  • A TLS probe retrieves the leaf certificate only: not the chain, protocol versions, cipher suites or key-exchange groups.
  • Keys held in HSMs or cloud KMS, keys embedded in source code, and application-level cryptography are out of scope for this version.
  • This is an inventory-based assessment, not a compliance certification.
